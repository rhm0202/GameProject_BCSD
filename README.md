# SoulSlayer

> 2D 액션 플랫포머 | Unity 2D | 3인 팀 프로젝트

색을 잃은 도시를 배경으로, 붓으로 적을 물리치며 세상을 정화해나가는 2D 액션 플랫포머 게임입니다.
적 처치 시 획득한 **소울(물감)** 로 캐릭터를 성장시키고 보스를 공략하는 것이 목표입니다.

> 벤치마킹: 할로우 나이트(Hollow Knight), 오리와 눈먼 숲(Ori and the Blind Forest)

## 담당 구현 (류황민)

### 플레이어 시스템
- 이동 / 점프 / 공격 기본 동작 구현
- **대쉬**: 방향키 입력 기반 대쉬 이동
- **무적 대쉬**: 소울 소모 시 대쉬 중 무적 판정 적용
- **포션 사용**: 체력 회복 아이템 사용 로직
- 피격 히트박스 연동

### 스킬 트리 / 소울 UI (`SoulManager.cs`)
- 소울 수집량 실시간 표시
- **패시브 스킬 트리**: 소울 소모로 단계별 스탯 강화 해금
- **액티브 스킬 (무적 대쉬)**: 스킬 트리와 연동하여 소울 소모 조건 처리
- 스킬 트리 UI 레이아웃 설계 및 구현

### 플레이어 HUD
- HP 바 실시간 동기화 (`PlayerUIManager.cs`)
- 포션 개수 / 소울 보유량 표시
- 스탯 최신화 기능 (피격·회복 시 즉시 반영)

### 씬 구성
- **타이틀 화면**: 처음부터 / 게임 종료 버튼 구현
- **게임 오버 씬**: 사망 시 전환 처리
- **체크포인트**: 도달 시 저장, 사망 시 해당 지점에서 리스폰

### 설정 UI
- 일시정지 메뉴 (ESC)
- 설정창 열기 / 닫기 버튼
- 타이틀 복귀 기능

### 팀 협업 관리
- GitHub Feature 브랜치 전략 운영
- 전체 PR 34개 머지 관리
- 머지 이후 발생한 충돌 버그 직접 수정
- 최종 빌드 담당

## 원안 대비 미구현 사항

5주 개발 기간을 고려해 초기 기획에서 범위를 축소하였습니다.

| 기획 항목 | 상태 |
|---|---|
| 소울 수집 및 스킬 트리 | ✅ 구현 |
| 체크포인트 저장 / 리스폰 | ✅ 구현 |
| 보스 2개 (상태 머신 패턴) | ✅ 구현 |
| 일반 몹 (근접 + 원거리) | ✅ 구현 |
| 더블점프 / 차징 공격 / 텔레포트 | ❌ 미구현 |
| 사망 시 소울 드랍 후 현장 회수 | ❌ 미구현 |
| NPC 상점 / 업그레이드 트리 | ❌ 미구현 |
| 보스 처치 시 컬러 해금 (흑백→컬러) | ❌ 미구현 |
| 5개 구역 메트로베니아 맵 | ❌ 미구현 (2스테이지로 축소) |
| 세이브 포인트 간 순간이동 | ❌ 미구현 |
